# Data Projects

This repository contains a collection of data analysis and machine learning projects I have completed. Each project demonstrates different techniques in data science, statistics, and programming.

---

## Content

### 1. Visualization of Data Scientists Salary
An exploratory data analysis project on salary trends for data science roles:
- Cleaned and processed job salary datasets.  
- Visualized compensation patterns across job titles, experience levels, companies, and locations.  
- Generated plots (box plots, histograms, line charts) to highlight differences in salaries.  
  
### 2. Predicting Glass Origins with Machine Learning
A machine learning classification project using the UCI Glass Identification dataset:
- Built models to classify glass types based on their chemical composition.  
- Applied feature preprocessing, visualization, and model evaluation.  
- Compared algorithms (e.g., Logistic Regression, Random Forest, SVM) for performance.  

### 3. Forecasting Groundwater Depth Using Time Series Models
A time series forecasting project focused on hydrological data:
- Used groundwater measurements from **Petrignano, Italy**.  
- Applied ARIMA and SARIMA models to predict groundwater depth
- Evaluated model diagnostics (ACF/PACF, residuals, Ljung-Box test) and forecast accuracy.  
- Provided insights for sustainable water resource management. 

### 4. Ebola Transmission Modeling with Dynamical Systems
A mathematical epidemiology project focused on modeling the spread of Ebola virus disease (EVD) using compartmental dynamical systems:
- Developed and analyzed discrete-time epidemic models (SIFR and SHERIF) to simulate Ebola transmission dynamics.
- Incorporated real-world epidemiological factors such as funeral transmission, hospitalization, incubation periods, and recovery processes.
- Derived equilibrium points and Jacobian matrices to study long-term stability and disease-free behavior.
- Simulated outbreak progression in R and visualized population transitions across susceptible, exposed, infected, hospitalized, funeral, and removed groups.
-Compared base and extended models to evaluate the impact of healthcare interventions and cultural practices on epidemic spread.
